# Live PC Health Tracker 🖥️⚡

A lightweight, real-time system performance monitor built with Python using a graphical user interface (GUI). This desktop utility tracks and displays live CPU and RAM consumption percentages, dynamically color-coding text notifications based on hardware workloads.

## 🚀 Features
- **Real-Time Tracking:** Refreshes performance metrics every second asynchronously without freezing the user interface.
- **Dynamic Workload Alerts:** Automatic font color status alerts (Green for stable loads, Red for high consumption warnings).
- **Lightweight Desktop Footprint:** Launches as a clean, native desktop window panel.

## 🛠️ Built With
- **Python 3**
- **Tkinter** (Native GUI management library)
- **psutil** (Process and system utilities library)

## ⚙️ Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd pc-health-tracker
   ```

2. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python sys_monitor.py
   ```
